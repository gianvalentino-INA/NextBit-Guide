How to Clean Install Windows or Linux on Any PC

By Gian Valentino Ampang

Setup

Introduction

Is your PC or laptop starting to feel sluggish during everyday use? Don't worry! Your device will run like brand new after you follow this tutorial. All you need is a USB drive (at least 8 GB), the right operating system, and a few minutes to follow these steps.

Step 1: Preparing Your USB Drive

First, head over to ventoy.net to download the Ventoy software. Ventoy makes your USB drive bootable and allows you to store multiple operating system ISOs (such as Windows and various Linux distributions) on a single drive.

  • Once the download is complete, extract the Ventoy folder and open it.
  • Run the Ventoy2Disk.exe file.
  • Select your plugged-in USB drive from the drop-down list and click Install.
CAUTION: Installing Ventoy will completely reformat your USB drive and erase all existing data on it. Make sure to back up any important files to another storage device before proceeding.

Accept the prompts to begin the formatting process. Once the installation is complete, click Update to ensure Ventoy is running the latest version. Close the Ventoy application and move on to the next step.

Step 2: Choosing and Downloading the OS Image (ISO)

In this step, you need to make an important decision: Windows vs. Linux?

Feature Windows Linux
Best For General compatibility, familiarity, & hassle-free gaming Older/low-end devices, full control, & lightweight performance
User Experience Plug-and-play, easy out-of-the-box experience Requires a learning curve and occasional tinkering
Hardware Support Works automatically with almost all hardware Requires checking component compatibility (e.g., Wi-Fi cards)
NOTE: For this tutorial, we will use Windows 11 as our primary example.

How to Download the Windows ISO:

  • Open your web browser, search for Windows 11 ISO, and click the official microsoft.com link.
  • Scroll down to the "Download Windows 11 Disk Image (ISO) for x64 devices" section.
  • Under Select Download, choose Windows 11 (multi-edition ISO for x64 devices) and click Download.
  • Once downloaded, cut and paste the ISO file directly into your Ventoy USB drive.
NOTE: Copy the ISO directly to the root of the Ventoy USB drive and not the VTOYEFI folder from the USB.

Step 3: The Installation Process

Shut down your PC or laptop. Turn the device back on while repeatedly pressing your BIOS key.

NOTE: The BIOS key varies depending on your device manufacturer, but common keys include F2, Delete, F10, Esc, or F12.

Once inside the BIOS menu, locate the Boot tab (if you don't see it, check under Advanced Settings). Change Boot Option 1 to your Ventoy USB drive. Save your settings and reboot your system.

Once the Ventoy menu loads, use the arrow keys to select your desired ISO file (e.g., Windows 11 or Linux) and press Enter.

Windows Installation Steps

  • Choose your language and keyboard layout (default is US).
  • Click Install Windows 11.
  • Accept the license agreement.
CAUTION: Custom/Clean installation will delete your files, applications, and settings on the target drive partition. Ensure your important data is backed up.
  • On the drive partitioning screen, select the target drive partition, delete older partitions if necessary, click Next, and let the installation complete.
  • Complete the initial setup screen (account creation, regional settings, etc.).

Linux Installation Steps (Example: Fedora)

  • Select the Fedora ISO from the Ventoy menu and boot into the environment.
  • Wait for the initial system commands to run until you enter the Live Boot desktop.
NOTE: Use the Live Desktop environment to test your hardware components—especially Wi-Fi cards, touchpads, and webcams—to confirm everything works out-of-the-box before installing.
  • Double-click the Install to Hard Drive app on the desktop.
  • Follow the step-by-step installer to configure your target drive, username, and system options.

There you have it fresh and snappy device like its brand new! dont forget to optimize you systems by debloating and tweaking some settings.
